<h1 align="center">🚀 AMPulseServer 1.0</h1>


<p align="left">
  Ambiente completo de desenvolvimento web com Apache, MariaDB e PHP para Windows 64 bits.
</p>

**Gratuito, de fácil uso e instalação.**
 
Desenvolvido para proporcionar um ambiente local rápido, leve, estável e prático para o desenvolvimento,
execução e testes de aplicações web.

Com um painel de controle simples e intuitivo, o AMPulseServer simplifica o gerenciamento do ambiente de 
desenvolvimento automatizando a configuração dos principais componentes de um ambiente PHP, oferecendo aos 
desenvolvedores uma alternativa prática para desenvolvimento local.

---

# ✨ Principais Recursos

## 🖥️ Painel Desktop de Gerenciamento

O AMPulseServer possui um painel de controle inspirado em ferramentas como XAMPP, permitindo o gerenciamento completo do ambiente local.

Principais funcionalidades:

* ✅ Iniciar, parar e reiniciar serviços do **Apache** e **MariaDB**.
* ✅ Gerenciamento de múltiplas versões do PHP.
* ✅ Alternância entre versões PHP com atualização automática dos arquivos de configuração.
* ✅ Configuração automática dos arquivos:

  * Apache
  * MariaDB
  * PHP
* ✅ Configuração e gerenciamento das portas dos serviços.
* ✅ Ferramentas de diagnóstico para identificação de problemas de inicialização.
* ✅ Acesso rápido aos arquivos de configuração.
* ✅ Atalhos e comandos auxiliares para manutenção do ambiente.

---

# 🌐 Painel Web para Diagnóstico e Monitoramento

Recursos disponíveis:

* 📊 Monitoramento em tempo real dos serviços.
* 🔍 Verificação das extensões carregadas do PHP.
* 🔍 Verificação dos módulos ativos do Apache.
* 🔗 Testes de comunicação entre:

  * Apache
  * PHP
  * MariaDB
* 🛠️ Ferramentas de diagnóstico para validação do ambiente.

# 💻 Requisitos do Sistema

## Sistema Operacional Recomendado

* Windows 10 64 bits ou Superior.

## Hardware recomendado

* Processador compatível com arquitetura x64
* Memória RAM: 4 GB ou superior
* Espaço em disco disponível para instalação dos componentes 1 GB

---

# 📦 Instalação

A instalação é realizada através do instalador criado com **Inno Setup**.

Após a instalação inicial, o próprio AMPulseServer realiza automaticamente:

1. Configuração do Apache.
2. Configuração do MariaDB.
3. Configuração das versões do PHP.
4. Ajuste dos arquivos de configuração.
5. Preparação do ambiente local de desenvolvimento.

Nenhuma configuração manual dos arquivos principais é necessária.

# 🎯 Objetivo do Projeto

O AMPulseServer foi desenvolvido para:

* Facilitar o desenvolvimento e testes de aplicações web 
 com a linguagem PHP em ambientes local.
* Reduzir a configuração manual do servidor.
* Disponibilizar múltiplas versões do PHP no mesmo ambiente.
* Auxiliar desenvolvedores durante o diagnóstico de problemas.
